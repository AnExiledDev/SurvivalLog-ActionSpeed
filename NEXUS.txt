Name: Action Speed
Summary: Makes everyday actions like eating, using furniture and treatment take less game time, lets your character walk faster, and can speed up crafting, brewing and cooking.

Description (BBCode):
Short chores eat your day in Survival Log. Action Speed lets you choose how much game time each kind of action takes, and how fast your own character walks. Everything is set in one config file.

[size=5]Main features[/size]
[list]
[*][b]Speed per action type[/b]: furniture use, food, treatment and other actions take half the game time by default. Every other type can be set too.[/*]
[*][b]Effects over time kept[/b]: sleeping, resting and similar actions keep the game's pace, so you never get less out of them.[/*]
[*][b]Single actions[/b]: set a speed for one action by its id.[/*]
[*][b]Action list[/b]: every action with its old and new time is written to a text file.[/*]
[*][b]Faster walking[/b]: your character walks 1.5 times as fast by default. Survivors and the robot keep the game's speed.[/*]
[*][b]Crafting, brewing and cooking[/b]: each has its own speed. Off by default.[/*]
[/list]
Action Speed writes no data of its own into your save and does not edit game files. It does change how much game time things take, and your save reflects that. You can remove it at any time; actions started after that take the game's own time again.

[size=5]Known issues[/size]
Speeds change game time, and game time is finicky: events, sleep and zombie waves all run on it, so odd timing is worth reporting. The crafting, brewing and cooking speeds are new in 0.2.0 and have not been run in the game yet. Back up your save before trying it for the first time. Speeds apply to everyone doing an action, survivors and the robot included. The workbench progress bar and the cooking bar can show the game's time while the work itself is shorter. If you run into anything strange, please tell me (see Feedback below).

[list]
[*]Survival Log 1.1.18317. A game update can break it until the mod is updated.[/*]

[/list]

[size=5]Installation[/size]
[list=1]
[*]Install [url=https://www.nexusmods.com/survivallog/mods/12]BepInEx[/url] [i](if no other mods were installed before, start the game once so BepInEx finishes setup, then quit)[/i].[/*]
[*]Put [font=Courier New]ActionSpeed.dll[/font] in the BepInEx&#92;plugins folder inside the game folder. Full path example:
[code]C:&#92;Program Files (x86)&#92;Steam&#92;steamapps&#92;common&#92;Survival Log&#92;BepInEx&#92;plugins&#92;ActionSpeed.dll[/code][/*]
[/list]

[size=5]Uninstall[/size]
Delete [font=Courier New]ActionSpeed.dll[/font] from the [font=Courier New]BepInEx&#92;plugins[/font] folder.

[size=5]Configuration[/size]
To change settings, edit [font=Courier New]BepInEx&#92;config&#92;com.dev.survivallog.actionspeed.cfg[/font] while the game is closed (see [url=https://github.com/AnExiledDev/SurvivalLog-ActionSpeed/blob/main/CONFIG.md]CONFIG.md[/url] for every setting). Changes apply at the next game start. Action ids are listed in [font=Courier New]BepInEx&#92;action-speed-actions.txt[/font].
